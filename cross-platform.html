Compare screens across frameworks

Compare a screen with its version on your app's other platform: what's missing, texts that changed, components that became others.

Try it

  1. With a SwiftUI, Compose or Flutter screen open, run View › Compare Screen With… and pick the other file.
  2. Sutra finds the matching screen and draws both side by side.
  3. Click a difference to open its line.

Port a screen with an agent

An agent ports a screen to another framework in your other project, then Sutra checks the result against the original and has the agent fix what differs.

Try it

  1. Run View › Port Screen To… and choose the other platform's project: Sutra recognizes it and suggests a file.
  2. Pick a model and start: the agent works in that project, following its conventions.
  3. When it's done, Sutra compares the port with the original, sends the agent the differences once, and shows the result.

The Agent Manager

Hand tasks to AI agents, run several at once, and review their plans, commands and changes before you keep them.

Try it

  1. Switch to Agents (⌘E), describe the task, and pick a model.
  2. Agents plan, read and edit; commands wait for your approval unless you allow them.
  3. Review the changes as diffs, or inline in the editor, and keep or undo them.
