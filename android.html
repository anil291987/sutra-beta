Jetpack Compose preview

Preview @Preview functions and Activities as you type, on phones, tablets, foldables and dual-screen devices, or render them on a real device.

Try it

  1. Open a Kotlin file with composables and press Preview.
  2. Pick the composable and the device; foldables show their crease, dual screens their hinge.
  3. Click an element to select its code.
  4. On device builds the app and shows the real composable from your phone or emulator.

Run on phones and emulators

Pick a connected phone or a running emulator and run the app; Devices & Tools starts emulators and checks the SDK.

Try it

  1. Pick a device in the run bar.
  2. Devices & Tools lists emulator images to start, and the Android SDK and JDK Sutra found.
  3. Run builds, installs and launches the app; the build's output streams into the Output panel.

Compose stability check

Find composables that recompose more than they need to, the unstable classes behind them, and how to fix them, from the Compose compiler's own reports.

Try it

  1. Run › Check Compose Stability compiles the app module once with the compiler's reports on. Your build files don't change.
  2. Findings list unstable parameters and classes, with fixes such as ImmutableList or @Immutable.
  3. The editor labels each composable: skips, skips by identity, or can't skip.

Kotlin playgrounds

Kotlin scripts with each line's value beside it, run on the JVM as you type.

Try it

  1. File › New Kotlin Playground creates a .playground.kts file.
  2. Type: it runs again and shows each value beside its line.
